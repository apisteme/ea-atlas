# Core pack (cross-industry)

The default when no industry pack fits, and the base every other pack builds on (profile defaults and the architecture glossary).

- Capability model: 10 L1, 50 L2, 100 L3 in the pack's own words, each L2 mapped by name to an APQC Process Classification Framework category (`std_ref`). Check APQC's current terms before republishing their framework text.
- Criticality concept: business-critical service. Third-party concept: critical supplier.
- Templates: 42 roles, 3 journeys (order and onboard, service request, complaint), 20 processes.
- Regulations: NIS2 (with an internal remediation target), GDPR (no readiness lens), EU AI Act (high-risk dates per the 2026 provisional agreement, to confirm).
- Glossary: architecture method, portfolio, commercial, resilience, integration, scenario and programme terms.
