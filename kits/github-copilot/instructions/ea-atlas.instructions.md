Files under `ea-atlas/` are an enterprise architecture atlas maintained with the enterprise-architecture-atlas skill (`.github/skills/enterprise-architecture-atlas/SKILL.md`). Follow that skill for any change.

- `ea-atlas/model/*.json` is the source of truth. Field rules are in the skill's `reference/model-schema.md`.
- `ea-atlas/repository/` and `ea-atlas/output/` are generated by `build.py`. Never edit them by hand.
- Every change to the model is a release: raise the version in `model/versioning.json` and add a history entry before building.
- No em or en dashes in model text.
